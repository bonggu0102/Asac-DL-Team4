# 원룸3D · 매물 사진 기반 3D 공간 재구성

매물 사진 3~5장으로 방을 3D 복원하고, 옵션 가구를 지운 뒤 내 가구를 배치해보는 뷰어.

ASAC 빅데이터 분석 11기 · 딥러닝 4조(5인) · 2026.07

![3D 복원 결과](docs/reconstruction.jpg)

## 배경

부동산 플랫폼의 매물 사진은 대부분 광각이라 공간감이 왜곡되고, 장수도 3~5장 수준.
평면도 기반 인테리어 서비스는 평면도가 없으면 사용 불가, VR 홈투어는 360도 카메라로 재촬영 필요.
이미 올라와 있는 사진만으로 어디까지 되는지 확인해봄.

## 파이프라인

```
사진 3~5장
  → DUSt3R 3D 복원 (Point Cloud)
  → YOLO11s + SAM2 가구 세그멘테이션
  → 주변 Point Cloud 색상으로 가상 벽 생성 (배경 보완)
  → TripoSR 가구 메쉬 생성
  → Three.js 뷰어 배치
```

## 결과

천장고 실측 2.3m에 대해 복원 측정값 2.25m / 2.02m, 오차 0.05~0.28m.
겹치는 영역만 충분하면 사진 3장으로도 광각이 보정된 공간 생성 가능.

## 복원 모델 선정

같은 방을 같은 장수로 복원해 DUSt3R와 VGGT 비교.

| | 10장 | 30장 | 100장 |
|---|---|---|---|
| DUSt3R | 우수 | 우수 | CPU 병목 |
| VGGT | 벽면 붕괴 | 미흡 | 처리 가능 |

실제 매물 사진은 3~5장 수준이라 대량 처리 시나리오가 아니고, 소량 이미지에서 격차가 분명해 DUSt3R 채택.
대량 처리가 필요해지면 VGGT 전환 고려.

## 배경 복원

가구를 지우면 그 자리에 빈 공간이 생김. 세 가지 시도.

- LaMa 인페인팅 — 3D 공간에서 바닥과 벽의 경계가 안 잡혀 정렬 깨짐
- 단색 벽 생성 — 깨끗하게 지워지지만 주변과 이질감
- 주변 Point Cloud 색상으로 가상 벽 생성 — 바닥과 벽 구분이 자연스러워 채택

## 담당 (이종선, 조장)

- 3D 복원 → 마스킹 → 가구 배치 전체 파이프라인 설계 및 통합 (`dust3r_pipeline_v1` ~ `v4_7`)
- DUSt3R 복원, SAM2 마스킹, TripoSR 가구 생성 구간 연결 및 결과 검증
- 발표
